# 配件大亂鬥 Gear Brawl

原創的多人連線亂鬥小遊戲，網頁版。伺服器只用 Python 標準函式庫，不用安裝任何套件。

## 啟動

- 雙擊 `start.bat`，或執行 `py server.py`
- 本機開 http://localhost:8765
- 同一個網路的朋友：開伺服器視窗上顯示的 `http://192.168.x.x:8765`
  （第一次啟動時 Windows 防火牆會詢問，要允許「私人網路」）
- 不同網路的朋友：需要路由器開 port 轉發，或用 Tailscale / ngrok 這類工具

## 操作

| 按鍵 | 動作 |
|---|---|
| ←↑↓→ | 移動 |
| V | 跳躍（可以跳回平台邊緣救自己） |
| X | 輕攻擊（連按三段，第三段會擊倒）；靠近木箱時撿起，拿著時再按丟出；空中按是下踢 |
| C | 重攻擊（出手慢、打中會擊倒） |
| Z | 按住瞄準：鎖定最近的敵人，移動時保持面向對方 |
| X+C | 一起按住防禦，只擋正面；會被炎拳大絕破防 |
| Z+X+C | 大絕（配件特技，有冷卻時間；防禦中再按 Z 也可以） |
| Esc | 換名字、配件、顏色 |

按下 X 或 C 後會等 0.05 秒判斷是不是組合鍵，所以單按 X / C 會比按下的瞬間慢一點點出招。

## 配件

| 配件 | X 輕攻擊 | C 重攻擊 | Z+X+C 大絕 |
|---|---|---|---|
| 炎拳手套 | 三段，近身、傷害最高 | 一般重擊 | 爆炎衝拳：向前突進，可破防並擊飛（小心衝出場外） |
| 疾風長棍 | 三段，攻擊距離最長 | 一般重擊 | 旋風斬：原地迴旋，打飛周圍所有人 |
| 雷光砲 | 三段，出手最快；**第三段是近距離五顆散彈** | 一般重擊 | 電漿彈：遠距離射擊，冷卻最短 |
| 巨劍 | 三段，最慢但距離最遠 | **按住 C 蓄力**，最多 1.2 秒、傷害 2 倍、範圍變大 | 破山斬：往前跳起砸地，落地衝擊波擊飛周圍 |
| 戰斧 | 三段，速度平均 | **丟出短程飛斧**（會飛回） | 迴旋飛斧：丟出後飛回，去程回程都能打中 |
| 影匕首 | **五段快速連擊**，第五段擊倒 | 一般重擊 | 影襲：瞬移到最近敵人背後背刺，背後攻擊擋不住 |
| 冰霜魔杖 | **發射冰彈（遠程）**，第三段大冰彈會擊倒 | 一般重擊 | 冰霜新星：冰凍周圍敵人 1.2 秒（冰凍中被打會解凍） |

## 規則

- 血量歸零或掉出平台算 KO，3 秒後重生（重生後有 2 秒無敵）
- 一局 3 分鐘，KO 最多的人獲勝；8 秒後自動開下一局
- 左上角「＋電腦／－電腦」可加入電腦對手練習

## 檔案

- `server.py`：網頁伺服器、WebSocket、遊戲邏輯（所有判定都在伺服器）
- `public/index.html`、`style.css`：大廳與 HUD
- `public/client.js`：連線、鍵盤輸入、畫面插值、HUD
- `public/render3d.js`：3D 畫面（Three.js，固定 55° 斜上方鏡頭）、角色與特效
- `public/assets/manifest.json`：指定角色模型檔，規格見 `美術規格.md`

3D 引擎 Three.js 是從網路（jsDelivr）載入，玩家的電腦需要能上網。
